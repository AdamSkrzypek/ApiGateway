# GW-012 — Wersjonowanie publicznego API

**Status:** Proponowane
**Obszar:** API Gateway i usługi
**Zależność:** GW-002

## Zakres i kryteria akceptacji

- Uzgodnić format wersji ścieżki lub nagłówka i zasady kompatybilności.
- Określić okres równoległego utrzymania wersji oraz sposób wycofywania endpointów.
- Udokumentować mapowanie każdej wersji publicznej na wersje API downstream.
- Potwierdzić przejście kompatybilnych i breaking zmian przez Gateway.
